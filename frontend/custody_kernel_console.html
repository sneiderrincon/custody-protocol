Custody Protocol Console
Consola de prueba para el API de custodia de dispositivos médicos — cada acción declara o consulta una aserción del log inmutable.
Sin verificar
Si la API corre en tu máquina (localhost) y ves un error de red al llamar, probablemente sea CORS: el backend FastAPI necesita CORSMiddleware habilitado para aceptar peticiones desde este origen del navegador.
POST /v1/custody/assertions
Es la clave de idempotencia del comando: reenviar el mismo claim_id no crea un duplicado.
provenance

GET /v1/custody/units/{unit_id}/history
Ingresa un unit_id para ver su cadena de custodia.
GET /v1/custody/units/{unit_id}/state?at=...
Consulta el estado derivado de una unidad en un instante específico.
GET /v1/custody/assertions/{claim_id}
Busca una aserción puntual por su claim_id para verificar su procedencia.
