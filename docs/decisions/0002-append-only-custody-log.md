# ADR 0002: Append-Only Custody Log

## Status

Accepted for Iteration 1.

## Context

The platform administers verifiable claims, never mutable device state.

## Decision

All writes enter through `DeclareCustodyAssertion`. The event store appends immutable
`CommittedCustodyAssertion` records and assigns global position plus stream version once.
Read models are regenerated by replaying the log.

## Consequences

- State is always derived.
- Claims are idempotent by `claim_id`.
- Corrections must be compensating assertions, never edits.
